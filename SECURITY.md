# Security Policy

## Supported version

Security fixes are applied to the latest revision of `main`.

## Reporting

Use GitHub private vulnerability reporting when available. Do not include real asset inventories,
employee details, credentials, or production database copies.

## Deployment warning

This demonstration intentionally omits authentication and authorization. Do not expose it to the
internet or store real company data without adding an identity layer, TLS, access controls,
backups, and an audit trail.
